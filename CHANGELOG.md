# cdin-x Changelog

All notable changes to this project will be documented in this file.

Based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/)

## [0.1.0] - 2026-09-25

### Added

- cdin-x extension system
- Core plugin engine: manager, config, manifest, command
- Plugin directory `X/` with 8 categories
- Essential plugins: core, vim, tab, window, treeview
- Plugin scaffolding (`make new-plugin`)
- Registry manifest system
- Git hooks for quality assurance
- Documentation structure
