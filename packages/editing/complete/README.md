# complete

Symbol-based completion for open documents.

Providers are registered rather than required, so a language plugin can add one
without complete knowing it exists.

Keys are in `keymap.lua` and scoped to a focused document view, so they do not
shadow anything while you are in a menu.

**Full page:** [autocomplete — what it does, what you press, and how it works](../../../docs/plugins/autocomplete.md)
